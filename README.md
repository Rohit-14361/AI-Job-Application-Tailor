# AI Job Application Tailor

An AI-powered document-based application built with **CrewAI, OpenAI LLMs, and FastAPI**. Users can upload their documents and ask questions based on the uploaded content. The system uses AI agents to analyze the provided information and generate relevant, context-aware responses.

## 🚀 Features

* 📄 **Document Upload** — Upload candidate documents for AI-powered analysis.
* 🤖 **CrewAI Multi-Agent Workflow** — Uses specialized AI agents for processing and reasoning.
* 🧠 **OpenAI LLM Integration** — Generates intelligent and context-aware responses.
* 💬 **Document Q&A** — Ask questions about the uploaded document.
* ⚡ **FastAPI Backend** — Provides fast and scalable REST APIs.
* 🔐 **Environment-based API Key** — OpenAI credentials are securely managed through environment variables.
* 📚 **Context-Aware Responses** — Answers are generated using information from the uploaded document.
